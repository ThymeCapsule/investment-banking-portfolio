# NatWest Group — Excess Return Valuation

## Objective

Estimate the equity value of NatWest Group using an excess-return (residual-income) framework suited to banks, where regulatory capital and tangible book value are central to the analysis.

## Methodology

The framework should:
1. Establish opening tangible ordinary equity / tangible net asset value on a consistent basis.
2. Forecast return on tangible equity and the cost of equity.
3. Calculate excess returns above the required return on equity.
4. Discount forecast excess returns and terminal excess returns.
5. Reconcile the resulting equity value with shares outstanding and market price.

## Key review points

- Source the risk-free rate, equity risk premium and beta used in CAPM; document the observation date and methodology.
- Reconcile tangible book value to the latest reported balance sheet and explain adjustments.
- Forecast CET1, capital requirements, dividends and buybacks consistently.
- Cross-check sustainable RoTE, payout assumptions and terminal excess-return fade.
- Expand the peer set beyond a small sample and explain differences in geography, business mix, accounting and capital structure.
- Compare the result with price-to-tangible-book and other relevant bank valuation metrics.
