# Signet Jewelers — Discounted Cash Flow Valuation

## Objective

Estimate the intrinsic value of Signet Jewelers using a discounted cash flow framework, with explicit operating assumptions and a transparent enterprise-to-equity value bridge.

## Methodology

The core framework is an unlevered DCF:

1. Forecast operating performance and unlevered free cash flow.
2. Discount forecast free cash flow using an appropriately supported WACC.
3. Estimate terminal value using a perpetuity-growth method.
4. Derive enterprise value and bridge to equity value.
5. Divide by diluted shares outstanding to estimate implied value per share.
6. Stress-test key operating and valuation assumptions.

## Key review points

The current workbook is a working model, not a final investment conclusion. The cash/debt and diluted-share bridge, lease treatment, normalisation of restructuring and other exceptional items, stock-based compensation, working capital, capital expenditure and terminal assumptions require further validation.

A previous model review identified an indicative output of approximately US$142.80 per share and a US$100 share-price placeholder in the one-page summary. These are not validated conclusions and should not be used as a target price.
