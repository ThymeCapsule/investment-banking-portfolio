# Northern Star Resources — Net Asset Value

## Objective

Assess the value of Northern Star Resources using an asset-level net asset value framework, reflecting the economics and risk profile of individual mining operations.

## Methodology

The analysis should forecast mine-level production, realised commodity prices, operating costs, sustaining and growth capital expenditure, royalties, tax, rehabilitation and closure costs. Forecast cash flows are discounted using a rate that is explicitly justified for the relevant asset and risk profile.

## Critical reconciliation before relying on outputs

A previous review identified a methodology inconsistency: the workbook's inputs included a 3.0x FY36 free-cash-flow residual value and the one-page summary showed a residual value of approximately A$4.15bn, while the README described residual value beyond FY36 as zero under a strict life-of-mine NAV approach.

Choose and document one methodology:
- **Strict life-of-mine NAV:** model cash flows only over the supported mine life, include closure and rehabilitation costs, and set terminal value to zero; or
- **Going-concern / residual value approach:** justify the post-FY36 value, forecast basis and terminal multiple, and explain why this is appropriate for the assets.

Do not mix these approaches without clearly explaining the distinction.

## Other assumptions requiring source support

- Commodity price and foreign-exchange assumptions.
- Production profiles, mine lives and project timing.
- All-in sustaining costs, development and sustaining capital expenditure.
- Royalty reference prices and applicable rates.
- Tax, rehabilitation and closure provisions.
- Net debt / cash and diluted shares.
- Discount rate, including nominal versus real consistency and currency.
