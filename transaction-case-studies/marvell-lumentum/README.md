# Marvell / Lumentum — All-Stock Combination in AI Optical Connectivity

<sub>TRANSACTION CASE STUDY · ANNOUNCED 2 NOVEMBER 2026 · ANALYSIS IN PROGRESS</sub>

## Case question

Does Marvell's proposed all-stock acquisition of Lumentum create sufficient strategic and financial value to justify the exchange ratio, dilution and integration risk? How does the transaction position the combined group in AI data-centre connectivity?

## Transaction snapshot

| Item | Announced terms |
|---|---:|
| Acquirer | Marvell Technology, Inc. (NASDAQ: MRVL) |
| Target | Lumentum Holdings Inc. (NASDAQ: LITE) |
| Announcement | 2 November 2026 |
| Consideration | **4.500 Marvell shares per Lumentum share** |
| Implied target enterprise value | **US$115bn** |
| Implied value per Lumentum share | Approximately US$1,132 |
| Premium | Approximately 23.9% to unaffected 28 October 2026 closing prices |
| Pro forma ownership | Marvell shareholders approximately 67%; Lumentum shareholders approximately 33% |
| Expected closing | First half of calendar 2028 |
| Conditions | Shareholder, regulatory and customary approvals |

The companies state that the combination is intended to address growing bandwidth requirements in AI infrastructure and the shift toward optical connectivity. Marvell's current chairman and CEO is expected to lead the combined company; three Lumentum directors, including its CEO, are expected to join the board.

## Why this is a compelling investment-banking case

1. **All-stock consideration:** The fixed 4.500 exchange ratio requires a transaction value and dilution analysis linked to both companies' share prices. The implied value changes with Marvell's share price until closing.
2. **Pro forma ownership:** The announced 67% / 33% ownership split provides a starting point for fully diluted share issuance, ownership and control analysis.
3. **Strategic industrial logic:** The deal combines optical and semiconductor capabilities in a market shaped by AI data-centre investment, bandwidth constraints and the move from copper to optical interconnects.
4. **Valuation discipline:** The US$115bn figure is an implied enterprise value for Lumentum. It must not be confused with equity value or used as a purchase multiple without reconciling debt, cash and other claims.
5. **Synergies and execution:** Product integration, R&D prioritisation, customer concentration, supply-chain capacity and technology roadmaps need to be tested rather than accepted as automatic value creation.
6. **Regulatory and timing exposure:** A long expected closing timetable through the first half of 2028 creates market-price, operating-performance and execution risk.

## Current status and limitations

**Status: announced transaction terms documented; independent valuation and merger model not yet completed.**

The 4.500 exchange ratio is fixed under the announced terms, but the market value of the consideration will fluctuate with Marvell's share price. The US$115bn figure is the announced implied enterprise value, not a completed independent valuation. No DCF, purchase multiple, EPS accretion / dilution or synergy value is published in this case study.

The transaction is subject to shareholder and regulatory approvals and is not yet completed. Management's strategic rationale is not independently verified value creation.
