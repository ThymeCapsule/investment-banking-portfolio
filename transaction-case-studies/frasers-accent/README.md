# Frasers Group / Accent Group — Takeover Valuation and Merger Analysis

<sub>FLAGSHIP TRANSACTION CASE STUDY · IN DEVELOPMENT</sub>

## Case question

Assess Frasers Group's A$0.65 per-share cash offer for the shares in Accent Group that it does not already own. What is the offer's implied valuation, how does it compare with Accent's standalone value under different operating scenarios, and what would the acquisition do to Frasers' earnings and capital structure?

## Transaction snapshot

The working model records a 100% cash offer at A$0.65 per share and an existing Frasers holding of approximately 22.9% at the launch of the offer. These terms and the current ownership position must be refreshed against the bidder's statement and latest substantial-holder disclosures before publication.

## Current analytical work

The local working workbook currently includes:
- Accent historical financial analysis and a standalone operating forecast.
- Management-plan, base and downside scenarios.
- Rent-adjusted FCFF DCF and valuation sensitivities.
- Offer premium and ownership-threshold analysis.
- A preliminary trading-comparables and precedent-transactions section.
- An illustrative Frasers EPS accretion / dilution calculation.

The current file is a **takeover valuation and illustrative accretion / dilution model**, not a complete integrated merger model. It has not yet been published as a workbook in this repository.

## Rebuild scope

The next version will add a full transaction architecture: transaction assumptions, fully diluted purchase-price bridge, sources & uses, financing and debt schedule, purchase-price allocation, pro forma balance sheet, combined income statement, phased synergies and integration costs, and fully linked accretion / dilution.

See [Frasers / Accent Model Review](../../docs/FRASERS_ACCENT_MODEL_REVIEW.md) for the detailed gap assessment and [Modelling Standards](../../docs/MODELLING_STANDARDS.md) for the release requirements.

## Required conclusion format

The final case study will answer:
1. What is the undisturbed share price and offer premium?
2. What equity value and enterprise value does the offer imply?
3. What does the standalone DCF and trading-comparables analysis indicate?
4. What are the key strategic and financial reasons for / against the transaction?
5. How do cash, debt and any scrip funding affect pro forma EPS and leverage?
6. What synergies are required for EPS neutrality and what is the downside if they are delayed or not achieved?
7. Which assumptions and transaction terms are most important to the valuation?
