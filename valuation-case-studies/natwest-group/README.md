# NatWest Group — Excess-Return / Residual-Income Valuation

## Case question

What equity value is implied by NatWest's tangible net asset value and the present value of expected returns on tangible equity above the cost of equity?

## Methodology

The model uses a residual-income framework suited to banks:

1. Establish opening tangible ordinary equity / tangible net asset value.
2. Forecast return on tangible equity (RoTE) and the cost of equity.
3. Calculate excess returns above the required return on equity.
4. Discount forecast excess returns and the terminal excess-return stream.
5. Reconcile implied equity value to diluted shares and the reference market price.

A conventional industrial-company EV/EBITDA DCF is not the primary valuation method for a deposit-taking bank.

## Scope and limitations

The current model is a simplified residual-income valuation. It does not fully forecast CET1, risk-weighted assets, regulatory capital requirements, through-cycle impairments, minimum capital buffers or distributions constrained by regulation. A short stylised earnings forecast is not a substitute for a bank operating and capital model.

The peer P/TNAV cross-check is indicative and uses a small, imperfect peer set. HSBC is a global cross-border reference rather than a pure domestic UK comparator.

## Required analytical work

1. Reconcile tangible equity to the latest reported balance sheet, including deductions and adjustments.
2. Forecast CET1, RWA, capital generation and regulatory buffers.
3. Forecast credit impairments by portfolio and through the cycle.
4. Link earnings, retained profits, dividends and buybacks through the capital roll-forward.
5. Test distributions against capital requirements and management buffers.
6. Calibrate RoTE, cost of equity, payout and terminal fade against history and peers.
7. Expand the peer set and compare P/TNAV, RoTE, cost of equity and payout on a consistent date.
